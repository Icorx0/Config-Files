## Themes

Saved Catppuccin theme configs. Copy the snippets from the relevant file into the active config to switch between dark (mocha) and light (latte).

- `nvim-mocha.lua` / `nvim-latte.lua` — nvim colorscheme line (paste into `nvim/init.lua`)
- `tmux-mocha.conf` / `tmux-latte.conf` — tmux status line colors (source or paste into `tmux/tmux.conf`)
